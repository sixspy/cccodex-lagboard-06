## 避开

## 互斥切口候选

- 超SLA冻结 vs 降级只读
- 补齐整源解冻 vs 按业务日窗口解冻
- 只认源时钟 vs 双时钟取严

## 时限档变更后重裁（已落地）

改时限档不可绕开到达重裁；不做纯显示切换。库文件与写路径在 `backend/readjudication/core.py`（重裁仓区）。

- 入口挂在页面「时限台策略」页（配置员/管理员），不另开重裁台。
- 甲路径：改档 + 旧到达重裁同笔事务，遇错整体回滚。
- 乙路径：旧到达先归档为历史快照，再按新档强制复检，全部通过后才改输出态；中断则快照保留、输出态保持未改。
- 甲乙不得混用；裁决卡写入即冻结，当天不可更换；偏离裁决卡即驳回并记「重裁偏了」。
- 到达主键全程保留；源目录、到达列表、策略附页、水位页、历史目录五处同按新档。
- 配置员与补采员改同一源互斥占槽，后手只留重裁争用痕。
